# See what others have reported

The bottom of the Tilbakemelding page lists the reports Myntos has read and
chosen to show, each in Myntos's own words, with where it has got to and the
answer. It is the quickest way to find out whether a problem is already known.

## They might ask

- «Vet Myntos om denne feilen?»
- «Kommer det lønn i Myntos?»
- «Hva jobber Myntos med nå?»
- "Is this a known bug in Myntos?"

## Steps

1. Open `https://myntos.no/tilbakemelding/` («Meld feil eller ønsker» in the
   footer).
2. Scroll to «Dette har andre meldt». Each entry shows the type («Feil»,
   «Forbedring», «Ønske»), the status («Lest», «Planlagt», «Ferdig», «Blir
   ikke gjort»), when it was reported, Myntos's description and Myntos's
   answer, if any.
3. If what they wanted to report is there, the answer is there too, and
   sending it again adds nothing.

## Good to know

- Most feedback is never shown here. Something missing from the list may well
  have been read and fixed.
- The list never shows what the sender wrote, only Myntos's own description,
  because people write what is on their screen.
- What Myntos does not do yet is listed at the end of «Funksjoner»
  (`https://myntos.no/funksjoner/#ikke-enna`), under «Det Myntos ikke gjør ennå».
