# File the VAT return your AI prepared

No AI and no program can send anything to Skatteetaten from Myntos, whatever
its key allows. Skatteetaten requires the person's own ID-porten login for
filing. An AI can prepare and check the MVA-melding and then **ask** the
person to file it; the request shows on «Godkjenning».

## They might ask

- «Kan KI-en sende mva-meldingen for meg?»
- «Agenten ber meg sende mva-meldingen. Hva gjør jeg?»
- «Kan agenten levere skattemeldingen?»

## Steps

1. Open «Godkjenning» (`https://myntos.no/godkjenning/`). The request reads
   ««<key name>» ber deg om at du sender mva-meldingen for <n>. termin <year>».
2. Read «Agentens forklaring:» for what the AI found (the amount, anything
   unusual).
3. Press «Gå til MVA-siden».
4. On the MVA page, choose that termin, log in with ID-porten, check the
   melding with Skatteetaten and send it, as described in
   https://myntos.no/llms/help/vat/send-the-vat-return.md.
5. The request on «Godkjenning» turns «Utført» by itself once the termin has
   been sent.

## Good to know

- If the person does not want to file it now, «Avvis» removes the request.
- The skattemelding cannot be filed from Myntos yet; when it can, it works the
  same way.
